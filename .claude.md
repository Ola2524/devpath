## Claude-Specific Guidance

### 1. Prefer `Edit` over `Write`

When modifying existing files, use `Edit` — not `Write`. `Write` overwrites the file and loses context. Only use `Write` for **new** files.

### 2. Run Typecheck Before Declaring Done

Before reporting a task complete in `apps/backend`, always run:

```bash
cd apps/backend && pnpm typecheck
Fix all errors. If you can't, explain why in your response.

3. Never Introduce New Dependencies
If a task seems to need a new package, stop and ask the user with:

The package name

Why you need it

What alternatives you considered

The dependency tree is deliberately minimal. See AGENTS.md §6.6.

4. Stay in Scope
The MVP scope is listed in AGENTS.md §7. If the user asks for something in "Out of Scope," confirm before building it.

5. Never Write N+1 Queries
See AGENTS.md §6.2. The rule is simple: never await a Prisma call inside a loop. Use include, select, or where: { id: { in: [...] } }.

6. Never Use console.log
Use logger from src/lib/logger.ts. See AGENTS.md §6.4.

7. Never Use any
Use unknown and narrow with type guards. any is banned. See AGENTS.md §6.1.

8. Always Validate Input with Zod
Use the validate middleware on every endpoint that accepts input. See AGENTS.md §6.3.

9. Always Throw AppError
Never throw new Error(...) in route handlers. Use BadRequest, NotFound, Unauthorized, etc. from src/lib/AppError.ts.

10. Log With Context
ts
// ❌ Bad
logger.error("failed");

// ✅ Good
logger.error({ err, userId, jobId }, "pipeline failed");
11. TypeScript Import Rules
Import paths end in .js (ESM + TS rule).

Use import type { X } for type-only imports.

Never use require.

12. Commits
Follow Conventional Commits. See AGENTS.md §6.7.

When Uncertain
Ask the user before assuming. This is safer than guessing, and it prevents:

Adding unwanted dependencies

Writing N+1 queries

Introducing security vulnerabilities

Committing secrets

Building out-of-scope features
